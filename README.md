# 🐾 Лапа помощи — панель волонтёра приюта

Дашборд из карточек-виджетов для волонтёра, который приходит в приют на смену.
Виджеты можно добавлять, сворачивать и удалять. Состояние панели и задачи
сохраняются в браузере.

**Сайт:** [ссылка на GitHub Pages]
**Репозиторий:** [ссылка на GitHub]

## Дизайн

Мягкий тёплый стиль: кремовый фон, пастельные карточки (у каждого виджета свой оттенок),
скруглённые кнопки, круглые галочки. Наверху — плюшевый маскот **Пушок** (нарисован в SVG):
он здоровается по времени суток и подсказывает, сколько задач осталось, что срочно нужно
и как одеть собак на прогулку. Плашки рядом показывают погоду, задачи, сбор и срочные нужды.

Карточки стоят в два ряда: «Сегодня» (погода, питомец, сбор) и «Списки» (задачи, нужды).
В ряду они одной высоты и делят ширину поровну, порядок не зависит от порядка добавления.
Планшет — две колонки, телефон — одна.

## Виджеты

| Виджет | Что делает | Источник |
|---|---|---|
| 📋 Задачи смены | Добавление, отметка выполнения и удаление задач | localStorage |
| 🌤️ Погода для выгула | Текущая погода, совет для прогулки с собаками, выбор города | [Open-Meteo](https://open-meteo.com/) (погода + поиск города) |
| 🐶 Ищет дом | Случайное фото собаки, кнопка «Следующий питомец» | [Dog CEO API](https://dog.ceo/dog-api/) |
| 🥫 Сбор на корм | Цель, прогресс-бар, быстрые и свои пожертвования, последние 5 взносов, смена цели | localStorage |
| 📦 Нужно приюту | Список вещей с пометкой «срочно», отметка «собрано», фильтры, срочное — наверху | localStorage |

Оба API работают без ключа. Секретных ключей в коде нет.

- Погода: `GET https://api.open-meteo.com/v1/forecast?latitude=55.7558&longitude=37.6173&current=temperature_2m,apparent_temperature,precipitation,wind_speed_10m,weather_code&wind_speed_unit=ms&timezone=auto`
- Собаки: `GET https://dog.ceo/api/breeds/image/random` → `{ "message": "<ссылка на фото>", "status": "success" }`

- Поиск города: `GET https://geocoding-api.open-meteo.com/v1/search?name=Казань&count=5&language=ru&format=json` → `{ "results": [{ "name", "latitude", "longitude", "country", "admin1" }] }`

Город выбирается прямо в карточке погоды («📍 Москва · сменить»): вводите название,
выбираете вариант из списка, и погода загружается для него. Выбор сохраняется в localStorage.
По умолчанию — Москва (`js/config.js`).

## Запуск

Проект использует ES-модули, поэтому `index.html` нельзя открыть двойным кликом:
нужен локальный сервер.

- **VS Code:** расширение Live Server → правой кнопкой по `index.html` → «Open with Live Server».
- **Или в терминале** из папки проекта: `python -m http.server 8000` и открыть http://localhost:8000

Сборка, npm и библиотеки не нужны.

## Публикация (GitHub Pages)

1. Загрузить файлы в репозиторий на GitHub (`index.html` в корне).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html
css/style.css
js/
  main.js              — запуск, кнопки добавления, подсказки
  Dashboard.js         — класс панели: addWidget / removeWidget / раскладка / save / restore / сводка
  Mascot.js            — класс маскота Пушка: моргает, следит глазами, говорит сводку по смене
  UIComponent.js       — базовый класс карточки: render, сворачивание, destroy
  storage.js           — безопасное чтение и запись localStorage
  config.js            — город и ключ хранилища
  widgets/
    ToDoWidget.js      — список дел (наследует UIComponent)
    ApiWidget.js       — общий класс сетевых виджетов: загрузка / ошибка / «Повторить»
    WeatherWidget.js   — погода (наследует ApiWidget)
    DogWidget.js       — «Ищет дом» (наследует ApiWidget)
    FundraiserWidget.js — «Сбор на корм» (наследует UIComponent)
    NeedsWidget.js     — «Нужно приюту» (наследует UIComponent)
```

## Как устроена надёжность

- Каждый виджет создаётся в `try/catch`: ошибка одной карточки не ломает остальные.
- Сетевые карточки показывают загрузку, результат или ошибку с кнопкой «Повторить».
  Проверяется `response.ok` и формат ответа; при сбое не показываются выдуманные данные.
- Запрос отменяется через `AbortController` при удалении карточки; таймаут — 10 секунд.
- `destroy()` снимает все обработчики и таймеры карточки, поэтому после многократных
  удалений и добавлений один клик выполняет одно действие.
- Повреждённый JSON в localStorage или запрет сохранения не ломают панель:
  она собирается заново и показывает подсказку.
- Повторно добавить виджет того же типа нельзя: появляется подсказка, существующая
  карточка подсвечивается.

## Нейросеть

Код получен по шагам с помощью **Claude** (Anthropic).

Полезные промпты:

1. > Создай дашборд «Панель волонтёра приюта» на HTML/CSS/ванильном JavaScript. Сверху — кнопки добавления виджетов, в центре — сетка карточек. Виджеты: задачи смены, погода для выгула, «Ищет дом». Стиль: тёплые цвета, скруглённые карточки, адаптация под телефон. Используй ES-модули. Без React, npm и сборки.

2. > Добавь DogWidget «Ищет дом» через Dog CEO API. Запрос: GET https://dog.ceo/api/breeds/image/random. Пример ответа: {"message": "...jpg", "status": "success"}. Используй только этот endpoint и поля, ничего не придумывай. Покажи загрузку, ошибку с кнопкой «Повторить», при удалении отменяй запрос.

3. > Добавь сохранение набора виджетов и задач в localStorage. После обновления восстанови классы из сохранённых данных, а погоду и фото запроси заново. Повреждённый JSON и запрет сохранения не должны ломать панель.
